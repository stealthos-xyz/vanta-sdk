# Upgrading safely

Install the exact signed archive, verify digest and signature with the repository verification command, retain the lockfile and rebuild both workers. Treat candidate builds as development only. Fetch the matching public partner configuration; never mix release versions, generations, pool addresses, fee policies or worker hashes. Deploy configuration and assets together, invalidate stale reviews, preserve encrypted journals and historical artifacts, and run the testnet acceptance checklist. For rollback, use an explicitly supported signed configuration and compatible historical resources; don't force an older bundle onto the current generation. Consult [CHANGELOG](../CHANGELOG.md) and signed publication. Release 0.4.65 is Chikyu testnet, not mainnet custody authorization.
