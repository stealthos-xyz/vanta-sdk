# SDK licensing and distribution

The SDK source is publicly visible for review and partner integration. Public visibility alone does not create an open-source license. Use and redistribution rights must be determined by the applicable StealthOS license or partner agreement.

The final first-party license and any redistribution terms require confirmation by the repository owner. This document does not grant additional rights. Existing third-party dependencies and bundled code retain their own licenses and notices; see `packages/vanta-sdk/dist/vendor/THIRD_PARTY_NOTICES.txt`.

The current SDK archives remain immutable and operator-signed. The candidate package includes standard npm repository metadata, a public-access publish configuration and a worker command. It remains marked private pending approval of first-party licensing and the npm organization/publishing authority. Do not publish an unsigned candidate as a supported release.
